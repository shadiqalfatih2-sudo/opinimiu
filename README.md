# Opinimiu

Kanal opini, analisis, data, dan perspektif muda tentang pembangunan Sulawesi Tengah.

## Stack
- Next.js + TypeScript
- Supabase Postgres/Auth/RLS
- Vercel
- Editorial custom UI

## Editorial model
Roles: contributor → editor → admin.
Workflow: draft → review → scheduled/published → archived.

## Product direction
Modern editorial publication for Sulawesi Tengah: minimal, elegant, data-aware, youth-driven, and constructive rather than merely pro/contra.
